# NYX

Plataforma web de gestión de turnos orientada a salones de belleza y centros de estética.

El sistema permite administrar turnos, clientes, empleados y disponibilidad desde una única plataforma.  
Actualmente se encuentra desplegado y en uso por un cliente real.

---

## 🚀 Funcionalidades principales

- Gestión de turnos y agenda.
- Administración de clientes.
- Gestión de empleados y disponibilidad.
- Configuración de horarios de atención.
- Integración con Google Calendar.
- Integración con Mercado Pago.
- Gestión de usuarios y permisos.
- Panel administrativo.
- Despliegue en producción.
- Configuración de dominio y servicios externos.

## 📌 Sobre el proyecto

NYX fue desarrollado de forma independiente como una solución para la gestión de turnos en negocios que trabajan mediante agenda.

El desarrollo incluyó todo el ciclo del proyecto:

- Análisis de requerimientos.
- Diseño del modelo de datos.
- Implementación de lógica de negocio.
- Desarrollo de funcionalidades.
- Integración con servicios externos.
- Pruebas.
- Despliegue.
- Mantenimiento y mejoras posteriores.

Uno de los principales objetivos del proyecto fue desarrollar una aplicación que pudiera utilizarse en un entorno real y no únicamente como ejercicio académico.

Actualmente, NYX es utilizado por un cliente real para gestionar su actividad diaria.

---

## 🔗 Integraciones

### Google Calendar

La plataforma permite sincronizar turnos con Google Calendar, facilitando la gestión de agenda y evitando tener que mantener calendarios separados.

### Mercado Pago

NYX incorpora integración con Mercado Pago para funcionalidades relacionadas con pagos y servicios dentro de la plataforma.
